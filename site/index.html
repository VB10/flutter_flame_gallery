Get started

Add the package, call show, use the result.

1 · Install

flutter pub add flame_gallery

2 · Open a game

import 'package:flame_gallery/flame_gallery.dart';

final result = await FlameGallery.show(
  context,
  game: const SweetSwap(
    config: MatchConfig(moveLimit: 15, targetScore: 1000),
  ),
  onEvent: (event) => analytics.log('$event'),
);

3 · Reward the player

if (result case GameResult(
  isCompleted: true,
  :final score,
) when score >= 1000) {
  grantCoupon();
}

Make it yours

Every game takes a theme, texts and its own rules. Swap the fruit for your products.

FruitSlice(
  theme: GameTheme(
    colorScheme: ColorScheme.fromSeed(
      seedColor: brandTeal,
      brightness: Brightness.dark,
    ),
    logo: const AssetImage('assets/logo.png'),
  ),
  strings: FruitSlice.stringsTr.copyWith(
    title: 'Yaz Kampanyası',
  ),
  config: SliceConfig(
    timeLimit: const Duration(seconds: 30),
    items: [
      SliceItem(
        sprite: const GameAsset('assets/can.png'),
        juiceColor: brandRed,
        points: 2,
      ),
    ],
    bomb: null,
  ),
)

Beyond colors

Backgrounds, your own dialogs and HUD, animated characters and sound effects, all without forking a game.

FlameGallery.show(
  context,
  game: FruitSlice(
    theme: GameTheme(
      background: const GameBackground.gradient(
        LinearGradient(colors: [teal900, teal500]),
      ),
      themeData: myAppTheme,
    ),
  ),
  // replace any built-in overlay
  overlays: GameOverlayBuilders(
    start: (context, ui) => MyBrandDialog(onStart: ui.start),
    gameOver: (context, ui) => MyResultSheet(onClose: ui.close),
  ),
  // your audio package plays the cues
  sounds: CallbackSounds((cue) => player.play(cue.name)),
);
You wantYou use
Color, gradient or image behind the gameGameTheme(background:)
Your design system in menusGameTheme(themeData:), GameOverlayBuilders
Animated runner or coinGameAnimation via RunnerSprites
Sound effectsGameSounds / GameSoundCue (no audio dependency)
Custom difficulty numbersSliceDifficulty.normal.copyWith(...)
